# SubMerger 系统全面优化与重构方案

## 1. 方案背景与目标
SubMerger (v6.2.0) 具备成熟的订阅聚合、微服务测速、节点管理与多用户隔离能力。为进一步提升系统工程质量与人机交互体验，开展覆盖前端视觉、组件工程化、后端架构治理与核心交互的系统性优化重构。

## 2. 阶段规划与落地执行记录

### 阶段一：前端 UI 视觉与关键交互美化 [已完成 ✅]
- [x] **修复 Tailwind 动态类名编译截断 Bug**: 在 `submerger/src/pages/Dashboard.jsx` 中建立静态 `COLOR_STYLES` 字典（覆盖 `text`、`bg`、`border`、`badge`、`progress` 等），杜绝 Tailwind purge 导致生产环境丢失样式。
